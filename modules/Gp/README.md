# GP Overview — Mockup

Archivos:
- `gp_overview_mockup.svg`: mockup (desktop) de la sección **GPs Overview**.
- `index.html`: mockup en HTML (misma sección).

Uso:
- Abrir el `.svg` en el navegador o en Figma/Illustrator.
- Abrir `index.html` en el navegador.

Foto / captura (opcional):
- Si quieres que el HTML muestre la captura del sheet automáticamente, guarda la imagen como `source.png` en esta misma carpeta.
- Alternativamente, usa el botón **Cargar imagen** dentro del HTML para previsualizarla.
